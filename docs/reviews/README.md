# Independent engineering reviews

Record reviews as `phase-task-review.md` with reviewer/execution tool, implementation owner, branch and commit, working-tree scope, requirements, inspected files, findings by severity/location, validation commands/results, inherited risks, limitations, and disposition.

An implementer's self-check is not an independent review. Start reviews read-only; run generated-output checks in a temporary copy when repository modifications are prohibited. Record skipped checks honestly. Approval to review is not approval to fix, commit, push, merge, or deploy.

The native Cursor badge task requires an independent Codex or human review. That review is recorded in [phase1-cursor-validation-review.md](phase1-cursor-validation-review.md) for the original two-file extraction; the committed reference tree also changes `app/page.tsx`, which remains unreviewed independently (see the scope note there). Do not create a Devin report file until the specified review/authorization occurs.

**Additions accepted under [decision 0003](../decisions/0003-multi-agent-operating-model.md) (2026-10-08).** Each review record also states: the full implementation SHA, tree SHA, and base; how provenance and Git object integrity were verified (see the [artifact handoff standard](../standards/artifact-handoff.md)); each claim marked **verified by the reviewer**, **agent-reported**, or **historical**; findings as PASS, WARN, or FAIL with file and line references; and the reviewer's identity, tool, and model if exposed. The reviewer must not be the author, tester, or remediator of the change, and Cursor cannot independently approve its own implementation. Codex stays read-only; Cursor or an authorized human commits its output verbatim. A remediation commit needs a new review of the new SHA. Review depth and any ChatGPT architecture cross-review follow the risk class in the [orchestration standard](../standards/agent-orchestration.md).
