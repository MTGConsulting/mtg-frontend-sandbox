# Independent engineering reviews

Record reviews as `phase-task-review.md` with reviewer/execution tool, implementation owner, branch and commit, working-tree scope, requirements, inspected files, findings by severity/location, validation commands/results, inherited risks, limitations, and disposition.

An implementer's self-check is not an independent review. Start reviews read-only; run generated-output checks in a temporary copy when repository modifications are prohibited. Record skipped checks honestly. Approval to review is not approval to fix, commit, push, merge, or deploy.

The native Cursor badge task requires a later independent Codex or human review. Devin's readiness assessment must initially be returned as task output; do not create its proposed report file until the specified review/authorization occurs. No Cursor or Devin review is claimed as completed here.
